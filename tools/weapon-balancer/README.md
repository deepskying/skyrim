# 武器平衡工具（Weapon Balancer）

一个本地网页小工具，用来规范 Skyrim SE 载入顺序里**模组新增武器**的伤害与攻速。

- 读取当前 MO2 档案的载入顺序（`plugins.txt` / `loadorder.txt` / `modlist.txt`），
  解析全部插件里的 `WEAP` 记录，并按覆盖顺序合并出**最终生效**的数值。
- 顶部按动画类型分页：单手剑 / 匕首 / 单手斧 / 单手钉锤 / 双手剑 / 双手斧类 / 弓 / 法杖 / 弩 / 其他。
  双手斧、战锤、镰刀共用动画类型 6，因此归为同一类（这是按动画类型分类的必然结果）。
- 每个类别可以单独设定**伤害上限**与**攻速上限**（伤害 0–100 整数、攻速 0–2 小数，超范围会红框并阻止提交），
  点“一键调整本类”后，超过上限的武器被压到上限，未超上限的一律不动。
- 武器列表可以搜索、筛选、逐条取消纳入，也可以展开任意一把做**单把精确修改**。
- “K 值 + 按 K 生成全部类别上限”会用 `原版同类别最高伤害 × K` 填好建议值，再手工微调。
- 变更先进入右侧预览，确认无误再导出 CSV 清单。

## 运行

**方式一：双击 EXE（推荐）**

`C:\Users\linos\Desktop\games\+skyrim\TOOLS\武器平衡工具.exe`

单文件打包，无需安装 Python。双击后浏览器自动打开 <http://127.0.0.1:8752/>，
命令行窗口就是工具本体，关掉即停止。可写数据（`state.json`、`cache\`、`output\`）
放在 exe 旁边的 `武器平衡工具-data\` 目录里。

重新打包（改过代码之后）：双击 `打包exe.bat`，它会重新构建并复制到 TOOLS。

**方式二：直接跑源码**

```powershell
python tools/weapon-balancer/server.py
```

默认读取 `C:\Users\linos\Desktop\games\+skyrim\MO2` 与 `SkyrimSE\Data`，也可显式指定：

```powershell
python tools/weapon-balancer/server.py --mo2 "D:\MO2" --data "D:\SkyrimSE\Data" --profile "-std-"
```

浏览器会自动打开 <http://127.0.0.1:8752/>。常用参数：`--port`、`--no-browser`、`--rescan`（忽略扫描缓存）。

## 目录

| 路径 | 说明 |
|---|---|
| `server.py` | 本地 HTTP 服务 + API |
| `scan.py` | 载入顺序解析、`WEAP` 读取与覆盖合并、类别定义 |
| `esp.py` | 极简 TES4 插件读取器与 `.STRINGS` 本地化字符串解析 |
| `plan.py` | 上限 → 变更清单的计算与 CSV 输出 |
| `write.py` | 生成 ESL 补丁插件（记录覆盖 + FormID 重映射 + 自检） |
| `web/` | 前端页面 |
| `state.json` | 上限、单把设定、筛选与选项（自动生成） |
| `cache/weapons.json` | 扫描缓存，载入顺序变化时自动失效（自动生成） |
| `output/*.csv` | 导出的变更清单（自动生成） |

## 生成补丁插件

预览确认后点“生成补丁插件”，会在 `MO2\mods\武器平衡-WeaponRebalance\` 下写出：

| 文件 | 说明 |
|---|---|
| `WeaponRebalance.esp` | ESL 标记的覆盖补丁，只包含需要改数值的记录 |
| `meta.ini` | MO2 的模组信息 |
| `WeaponRebalance.esp.bak-*` | 覆盖同名补丁前的自动备份 |

生成规则：

- 只改 `DATA.Damage`、`DNAM.Speed`、`DNAM.Animation Attack Mult`、`CRDT.Damage`，
  其余子记录（模型、音效、关键词、附魔、装备类型、模板）完整复制。
- 记录按覆盖顺序合并后再写出，等于游戏最终看到的版本；不支持部分记录。
- 记录里所有 FormID 会从来源插件的主文件索引重映射到补丁自己的主文件列表，
  包括同插件内部的自引用（第一人称模型等）。
- 补丁**不会**修改任何原有模组文件；同名的旧补丁先备份再替换。
- 无法安全转换的记录会被跳过并在结果里列出：含脚本数据 `VMAD`、
  可破坏数据 `DEST`、贴图替换 `MODS`/`MO3S` 的记录（这些结构里的 FormID
  需要额外解析，写错会破坏脚本或贴图，因此宁可跳过）。
- 生成后自动复检：重新读取补丁，逐条核对伤害/攻速/暴击是否与预览一致，
  并检查主文件数量与 ESL 标记。

**用完记得在 MO2 里启用 `武器平衡-WeaponRebalance`，并把它排在这批武器模组之后。**

## 默认的纳入规则

参与调整的武器：模组新增、可装备、未附魔、非法杖、伤害大于 0。
默认跳过：原版武器、Summermyst 这类自动生成的附魔副本、NPC 专用武器、法杖、无伤害记录。
所有这些都可以用界面上的筛选开关打开。

被改动的武器会按原版规则同步暴击伤害（`伤害 × 50%`），并把不等于 1.0 的
“攻击动画倍率”归一为 1.0；两项都可以关掉。
