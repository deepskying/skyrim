# 全武器四色材质

原有156把正式武器中，巨剑12把与第二组单手斧4把已覆盖，本次补齐其余140把。两把历史材质试样保持原样。

红：熔光脉络；绿：星砂琉璃；蓝：层叠晶片；紫：云雾光晶。所有主体保留原有全身发光倍率，不透明表面用贴图表现层次。弓弦和亮边保留原shader；流萤·折岚的折面也覆盖同色材质，保留较低的原发光倍率。

- `overview-1.jpg` 至 `overview-4.jpg`：42个代表模型的贴图分布检查。
- `render_nif.py`：从独立stage读取实际NIF，用Blender近似渲染；非游戏实拍，不用于证明拉弓动画或粒子播放。
- `preview-keys.json`：预览名单。
- `source/apply_collection_materials.py`：仅替换主体/折面shader的材质字段及贴图链接。

重建stage需要0.46.0安装包中的data运行文件作为baseline/和data/，以及对应158条catalog快照。脚本不会直接写入正式data。验证逐块比较所有非材质数据、保留Skinned旗标并通过原生NIF读取检查贴图路径。最终以游戏内效果为准。
