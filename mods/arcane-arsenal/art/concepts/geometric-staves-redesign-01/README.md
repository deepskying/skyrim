从左到右（暂名）：

1. **余烬·叠炬**：斜向实体叠片，错开高低与朝向，从上杖身递进成杖头。
2. **流萤·回梭**：双带形成狭长梭形镂空，前后交错一次，延伸到杖颈。
3. **寒汐·悬阶**：短棱柱围绕中心轴分层错转，形成阶梯轮廓。
4. **梦隙·折界**：宽三角折面围成立体空腔，偏心尖端与上杖身衔接。

共同约束：可握持的细长几何握柄；实体厚度、真实镂空；不新增皮革、枝叶、首饰或透明水晶材质。建模时需复核杖头比例、掌心净空和前后结构。法术已进入原型实现，游戏内表现仍待实测。
