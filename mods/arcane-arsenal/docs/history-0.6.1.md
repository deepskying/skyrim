# 异界弓藏 · Arcane Arsenal 0.6.1

白羊系列现在只保留红、绿、蓝、紫四把。鎏金·白羊、夜蚀·白羊、月华·白羊已从插件、测试箱、配方、拉弓脚本和运行资源中移除。此前八把实验武器保留作对照，合集共十二把。

## 0.6.1 亮度微调

按游戏反馈，四把白羊弓的主体、亮边和弦的自发光参数统一降低 25%。保留 0.6.0 的造型、粗细、配色、贴图及粒子强度，方便单独比较弓身亮度。更新后重启游戏并重新装备现有弓即可，不需要重新取弓。参数降幅不等于屏幕亮度的线性降幅，实际观感需复测。

保留四种独立几何造型。本次在 0.5.1 基础上将轮廓线再加粗约 41%、细弓轨加宽约 46%，羊角与厚度也相应增大；双轨间距随之扩大，避免挤成一条线。握把位置、弦端与原版七骨骼层级不变。

配色允许邻近颜色组合，使用较深的有色主体和更亮的青绿、青蓝、浅紫轮廓，取消深灰底图。红弓直接复用初版红色几何弓的颜色底图、法线和发光贴图；其余三把使用较亮的独立配色底图，并共用原版红弓的法线与发光贴图。

四把继续使用自发光 Glow Shader。主体、边线、弦的发光强度分别为：红 6/12/7.5、绿 7.5/15/10.5、蓝 7.5/18/12、紫 9/18/12。模型内没有滚动变色材质，不重新添加预设附魔；此前红色流动来自吸收生命附魔的 EnchRedFXShader，该附魔在 0.5.1 已移除。

模型自发光与屏幕上的泛光不是同一项设置。这里已调整贴图、色相、亮部面积与发光参数，但没有改动用户的 ENB 配置；游戏内的荧光观感仍需要本轮复测，不能以 Blender 预览代替。

## 一次取出四把

完全退出游戏后更新，再从 MO2 的现有 SKSE 启动。控制台输入：

```text
help "AAAriesTestChest" 4
```

找到 **白羊座·试武箱** 的 CONT 记录，再用查询到的完整编号生成箱子：

```text
player.placeatme <CONT的完整编号> 1
```

箱内是四把白羊弓各一把和铁箭 200 支。不要输入尖括号文字，也不要把表格中的本地编号直接当完整编号；FE 加载前缀以实际查询为准。请生成新箱子，旧箱子的存档库存不会可靠地随插件重建。

单独取弓可以按表中的搜索名查询 WEAP，再执行 `player.additem <完整编号> 1`。`AAAllBowsTestChest` 对应的 **异界弓藏·试武箱** 内有全部十二把，包含此前八把实验武器。

四把保留各自原来的 FormID，不把旧黄、黑、白弓改成其他武器。被移除的三个颜色不再可用，其九个记录编号保留为空缺，不重用于其他物品。本次没有编辑用户存档。

## 粒子与测试

保持上一版已经增强的原生粒子：每把六个发射点，位于握把两侧弓翼并随动画骨骼运动。红色火屑、青绿萤点、蓝青冰屑和紫色菱形碎光与新版亮边配色对应。

拉弓时显示并持续产生粒子，放箭、取消、收弓、换武器时隐藏。没有新增六芒星、环绕轨道、箭矢拖尾或命中特效。旧赤光·叠弦的额外拉弓六芒星继续关闭，旧弓身静态星形保留。

每个发射点每秒 14–18 个粒子，池容量 48，六个发射点每个视角上限 288，两个视角总池上限 576。通常每个视角约 92–126 个粒子。隐藏用独立节点的 0.0001 非零缩放保持变换有效，模拟本身仍循环运行。脚本只控制玩家，暂不支持 NPC 拉弓触发。

本轮重点比较：

1. 在截图相同的室内环境，与初版赤光弓比较荧光观感；再在暗处观察一次。
2. 青绿、蓝青、蓝紫是否比原来的高饱和单色更合适，亮边是否过白或盖住几何。
3. 第一、第三人称拉满弓时，弦端与握持是否仍对齐，加粗的弓翼是否挡准星。
4. 拉弓、取消、放箭及切换视角后，粒子是否正常出现和清理。

## 安装与属性

安装包：`ArcaneArsenal-0.6.1.zip`。MO2 模组名沿用 **Arcane Arsenal - Bow Collection**，插件沿用 **ArcaneArsenal.esp**，元数据版本为 **0.6.1**。已同步安装时不需要再导入压缩包；MO2 若缓存旧版本号，刷新或重启即可。

插件保持 ESL 标记，使用轻量槽位；头版本 1.7、记录版本 44，兼容 Skyrim SE 1.5.97，无需扩展 ESL 补丁。主文件只有 Skyrim.esm；拉弓特效依赖已安装的 SKSE64 2.0.20 / NetImmerse，无新增 DLL，不需要运行行为生成器。

四把白羊弓基础伤害 20、重量 6、价值 1800，没有预设附魔。均可用银锭 2 个、精炼孔雀石 3 个在锻造台制造；没有磨刀石强化配方。此前八把武器的属性与资源保持不变。

安装工具备份所有替换与删除的文件，再校验 56 个运行文件。备份位于工程 `build/mo2-before-0.6.1-*`。更新只维护本模组，不更改加载顺序、其他模组、游戏 Data、ENB 或存档。

## 验证与工程记录

- 四把均通过原版骨骼层级、权重、三角面、贴图与发光参数检查，并比较三组受控姿态的导出前后位置。
- 每把 96 个粒子块经过原生 nifly 读取、另存、引用归一化后的字段比较；发射点位置、父骨骼、容量和寿命另行检查。
- xEdit/SSEDump64 检查通过：十二条 WEAP、十二条 STAT、十二条 COBJ、两条 CONT、一条 QUST，共 39 条新记录。九条退役记录不存在；保留武器记录逐字节不变，两个箱子仅修改库存。
- 拉弓脚本只查找四把白羊弓，保留原任务和别名身份；Creation Kit 编译零错误、零警告。
- 安装包与 MO2 的运行文件逐文件校验，并检查退役资源确实不存在。

以上为离线验证，本轮游戏表现待用户复测。`art/aries-bows-lineup.png` 是实际源模型渲染，未模拟原生粒子，不是游戏截图。

`source/aries_catalog.json` 保存当前四把的造型、颜色和粒子参数；`source/catalog.json` 保存全部武器及固定记录编号。`source/retired_weapons.json` 保存退役编号，`source/obsolete_assets.json` 列出本轮需要清理的运行资源。源概念与旧制作记录保留在 art/concepts 和 docs/history-*，不进入运行包。

构建顺序：在 Blender 中按四个 key 运行 `build_aries.py`，再运行 `build_aries_particles.py`；用普通 Python 运行 `compile_draw_fx.py`、`build_plugin.py`；完成验证后运行 `package_mod.py`、`install_mod.py`。模型重建会生成 `build/aries-base`，必须再追加粒子。
