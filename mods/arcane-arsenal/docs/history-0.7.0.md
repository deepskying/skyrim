# 异界弓藏 · Arcane Arsenal 0.7.0

新增四把金牛座几何发光弓，每把使用独立轮廓和拉弓粒子。合集共十六把：四把金牛、四把白羊、八把早期实验武器。

主体为有厚度的几何自发光材质，没有预设附魔或滚动红色覆盖层。主体、亮边、弦的发光参数沿用白羊 0.6.1 降低后的数值：红 6/12/7.5、绿 7.5/15/10.5、蓝 7.5/18/12、紫 9/18/12。由于发光面积不同，同参数下的屏幕亮度仍可能不同，本轮需在游戏中比较。

弓翼亮边与实体轨道共用对应截面的骨骼权重，避免弯曲后亮边剥离。握把、弦端及原版七骨骼层级沿用已验证的基础。

## 一次取出四把金牛弓

更新后重新从 MO2 的现有 SKSE 启动游戏，控制台输入：

```text
help "AATaurusTestChest" 4
```

找到 **金牛座·试武箱** 的 CONT 记录，用查到的完整编号生成箱子：

```text
player.placeatme <CONT的完整编号> 1
```

箱内有四把金牛弓各一把、铁箭 200 支。尖括号内容需要替换；FE 加载前缀以查询结果为准，不要直接输入上表的本地编号。生成新箱子即可，旧箱子的存档库存不一定随插件更新。

`AAAriesTestChest` 仍提供四把白羊；`AAAllBowsTestChest` 现在提供全部十六把。也可按表中的搜索名查询 WEAP，再执行 `player.additem <完整编号> 1`。

## 粒子与复测

每把金牛弓有六个原生粒子发射点，位于握把两侧弓翼并跟随骨骼。每点每秒 10–14 个，寿命 1–1.4 秒，容量 48；每个视角通常约 78–84 个存活粒子，六点总容量上限 288。

拉弓期间显示粒子；放箭、取消、收弓或换武器时隐藏。脚本也同步第一、第三人称节点。当前粒子是局部持续发射，没有实现概念图中的完整环绕轨道、放箭爆发、箭矢拖尾或命中特效。没有新增六芒星。

脚本使用已有 SKSE64 / NetImmerse，只控制玩家，暂不支持 NPC 触发。隐藏节点使用 0.0001 非零缩放保持变换有效，粒子模拟仍循环运行。

复测重点：

1. 四种弓翼的厚度与开口造型是否满意，第一人称角叉是否遮挡瞄准。
2. 室内与暗处的发光是否合适，尤其青蓝和浅紫亮边是否过亮。
3. 握持、拉满、放箭时，弓翼亮边和弦端是否保持贴合。
4. 拉弓粒子是否足够明显，取消、换武器和切换视角后是否正常隐藏或恢复。

## 安装与兼容

安装包：`ArcaneArsenal-0.7.0.zip`。MO2 名称沿用 **Arcane Arsenal - Bow Collection**，版本号 **0.7.0**，插件仍为 **ArcaneArsenal.esp**。已同步到 MO2 后无需再导入压缩包；版本列若缓存旧值，刷新或重启 MO2。

ESP 保持 ESL 标记，头版本 1.7、记录版本 44，目标 Skyrim SE 1.5.97；主文件只有 Skyrim.esm。拉弓粒子使用现有 SKSE64 2.0.20，无新增 DLL 或行为生成步骤。

金牛弓基础伤害 20、重量 8、价值 1800，无预设附魔。锻造消耗银锭 2 个、精炼孔雀石 3 个，没有磨刀石强化配方。

原十二把武器的记录、模型与贴图保持 0.6.1 状态。黄、黑、白三把白羊仍已移除，九个退役编号不再使用。新金牛记录追加在 000830–00083C；原任务、脚本名称、白羊箱子和既有 FormID 保持不变。拉弓脚本在读档时重新填充八把星座武器列表。

安装工具备份所有替换文件，并逐文件校验 62 个运行文件：16 NIF、43 DDS、1 ESP、1 PEX、1 SEQ。备份位于工程 `build/mo2-before-0.7.0-*`。仅维护本模组，不修改其他模组、加载顺序、游戏 Data、ENB 或存档。

## 离线验证与工程

- 四把模型检查骨骼层级、权重、面数据、贴图、自发光参数，并比较三组受控姿态的导出前后位置。
- 原生粒子经 nifly 读取、另存及引用归一化后比较；每把六个系统、96 个追加块，另查发射位置、父骨骼、寿命、容量与隐藏变换。
- 插件校验中文名称、模型引用、旧记录身份和三个测试箱库存；xEdit/SSEDump64 检查 16 WEAP、16 STAT、16 COBJ、3 CONT、1 QUST，共 52 条记录。
- Creation Kit 编译拉弓脚本，安装包和 MO2 逐文件校验。

以上是离线验证，金牛弓的游戏表现待复测。`art/taurus-bows-lineup.png` 为实际源模型渲染，`art/taurus-bows-flex.png` 为受控变形预览；两者均不是游戏截图，也未模拟原生粒子。

金牛参数在 `source/taurus_catalog.json`，全部固定记录编号在 `source/catalog.json`。实现与概念的对应说明见 `docs/taurus-design.md`，旧版说明见 `docs/history-0.6.1.md`。

构建：用 Blender 按四个 key 运行 `build_taurus.py`，再以 `--python build_aries_particles.py -- --taurus` 追加原生粒子。用普通 Python 运行 `compile_draw_fx.py`、`build_plugin.py`，验证后运行 `package_mod.py`、`install_mod.py`。金牛独立构建，不重建白羊模型。
