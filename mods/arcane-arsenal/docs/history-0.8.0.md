# 异界弓藏 · Arcane Arsenal 0.8.0

新增「几何律」系列：六种轮廓、四种配色，共二十四把。包含改名并更新粒子的三把旧赤光弓，以及二十一把新增武器。合集共三十七把：几何律 24、白羊 4、金牛 4、早期实验弓 5。

## 六种造型

| 款式 | 轮廓 | 几何碎光 |
| --- | --- | --- |
| 叠弦 | 保留早期层叠实心三角片与六芒星 | 短线光屑 |
| 旋序 | 保留早期重复三角框与六芒星 | 三角碎片 |
| 流菱 | 保留早期长菱框与六芒星 | 菱形碎光 |
| 六垣 | 从握把到弦端逐级缩小的六边形阵列，双层六边形核心 | 六边形空心光片 |
| 方旋 | 沿弓翼交错倾斜的方框，双层方形核心 | 方形光片 |
| 锋羽 | 向外展开的尖三角刃，交错实心与镂空，双层三角核心 | 尖细碎光 |

每种造型都有四种配色：**余烬**（红/玫红）、**流萤**（翠绿/薄荷青）、**寒汐**（冰蓝/青蓝）、**梦隙**（蓝紫/浅紫）。例如余烬·六垣、流萤·六垣、寒汐·六垣、梦隙·六垣。

新三款参考 `art/concepts/geometric-red-star-04` 的三张概念图，使用有厚度的几何自发光材质。原三款的基础几何来自 `art/geometry-templates`，四种配色共享各自轮廓和骨骼权重。没有新增拉弓六芒星；经典款的静态弓身六芒星保留。

## 发光与粒子

沿用 0.7.1 调低后的主体、亮边和弦参数，未恢复此前的高亮度：

| 配色 | 主体 | 亮边 | 弓弦 |
| --- | ---: | ---: | ---: |
| 余烬 | 1.8 | 3.6 | 2.25 |
| 流萤 | 2.25 | 4.5 | 3.15 |
| 寒汐 | 2.25 | 5.4 | 3.6 |
| 梦隙 | 2.7 | 5.4 | 3.6 |

旧三把余烬款的弦沿用其原值 2.4。几何律粒子发光统一为 2.4，比白羊的 3.6、金牛的 3 更低。

每把六个原生发射点，每点每秒 8 个粒子，寿命 0.9–1.4 秒，池容量 32。每个视角通常约 43–67 个存活粒子，六点容量上限 192。六种款式在 sprite、速度、寿命和发射方向上有区别；配色与弓翼亮边对应。

拉弓时显示粒子，放箭、取消、收弓、换武器时隐藏，同步第一与第三人称。当前为随弓翼运动的局部漂散，不是完整的环绕轨道、放箭爆发、箭矢拖尾或命中特效。脚本仅控制玩家，不支持 NPC 触发；隐藏用非零微小缩放，模拟仍循环运行。

## 一次获取二十四把

更新后从 MO2 的现有 SKSE 启动游戏，控制台输入：

```text
help "AAGeometricTestChest" 4
```

找到 **几何律·试武箱** 的 CONT 记录，用查询出的完整编号生成箱子：

```text
player.placeatme <CONT的完整编号> 1
```

箱内有二十四把几何律弓各一把和铁箭 200 支。尖括号内容需要替换，不要直接输入；FE 加载前缀以当前查询结果为准。测试箱本地编号是 00087C，不能单独作为控制台完整编号使用。

请生成新箱子。旧箱子已有的存档库存不一定随插件更新。优先用新箱子中的武器测试，尤其是旧三把的附魔移除效果。

原箱子保留：`AAAriesTestChest` 为四把白羊，`AATaurusTestChest` 为四把金牛，`AAAllBowsTestChest` 为全部三十七把。每个箱子都有铁箭 200 支。

## 旧弓升级与属性

原赤光·叠弦、赤光·旋序、赤光·流菱改名为 **余烬·叠弦、余烬·旋序、余烬·流菱**，本地 WEAP 编号仍为 000811、000814、000817，模型路径和物品身份保留。

三把原有的预设吸取生命附魔移除，因此不再自带吸血效果，也不再由该附魔产生流动红色覆盖。几何律全部二十四把均无预设附魔，基础伤害 20、重量 6、价值 1800，可用银锭 2 个、精炼孔雀石 3 个在锻造台制造；没有磨刀石强化配方。

旧拉弓六芒星实验节点从叠弦新模型中移除；新的六点粒子系统取代原单独红色粒子实验。原任务、别名和脚本身份保持不变，读档时填充全部 32 把受控武器（星座 8 + 几何律 24）。

另外十三把武器的记录、模型和贴图与 0.7.1 一致。退役的黄、黑、白白羊及九个记录编号继续保持空缺，不复用。

## 安装与复测

MO2 模组名 **Arcane Arsenal - Bow Collection**，版本 **0.8.0**；插件仍为 **ArcaneArsenal.esp**，保持 ESL 标记。已同步安装时，无需再次导入压缩包；若版本号缓存旧值，刷新或重启 MO2。

目标 Skyrim SE 1.5.97；头版本 1.7，记录版本 44，主文件只有 Skyrim.esm。粒子脚本沿用现有 SKSE64 2.0.20 / NetImmerse，无新增 DLL 或行为生成步骤。

本轮重点比较：

1. 六种轮廓是否清楚，六垣、方旋、锋羽的框线厚度与镂空比例是否满意。
2. 四种配色的亮度是否合适，是否再次出现轮廓被泛光淹没。
3. 第一人称握持与拉满弓时，核心和弓翼是否挡住瞄准，弦端是否对齐。
4. 拉弓粒子是否可见，放箭、取消、换武器、切换视角后是否正常隐藏或恢复。

## 验证与工程

- 二十四把均检查原版七骨骼层级、权重、贴图、自发光参数，并比较三组受控姿态导出前后的位置。
- 每把六个原生粒子系统，96 个追加块经 nifly 读写与引用归一化后比较，另查发射位置、父骨骼、容量、寿命和隐藏变换。
- 插件检查中文名称、模型引用、四个箱子库存、旧 FormID 和退役编号；xEdit/SSEDump64 检查 37 WEAP、37 STAT、37 COBJ、4 CONT、1 QUST，共 116 条记录。新增 64 条，范围 00083D–00087C。
- Creation Kit 编译脚本零错误、零警告；另外 57 个原运行文件与 0.7.1 逐字节一致。
- 安装包与 MO2 校验 86 个运行文件：37 NIF、46 DDS、1 ESP、1 PEX、1 SEQ。

以上为离线验证，游戏画面与动画仍需复测。`art/geometric-bows-lineup.png` 为实际模型总览，列按六种款式排列，行按红、绿、蓝、紫排列；`art/geometric-bows-flex.png` 为受控变形预览。两图均不是游戏截图，未模拟原生粒子或游戏 ENB。

安装包为 `packaging/ArcaneArsenal-0.8.0.zip`，替换文件备份在 `build/mo2-before-0.8.0-*`。安装仅维护本模组，不改其他模组、加载顺序、游戏 Data、ENB 或存档。

参数在 `source/geometric_catalog.json`，固定记录编号在 `source/catalog.json`。构建模型用 Blender 的 `--python build_geometric.py -- <key>`，追加粒子用 `--python build_aries_particles.py -- --geometric`。接着用 Python 运行 `build_plugin.py` 和 `compile_draw_fx.py`，完成验证后运行 `package_mod.py`、`install_mod.py`。

`art/geometry-templates` 保存三种经典几何的独立源文件，不依赖被覆盖的当前红弓。`dim_emission.py` 是从 0.7.0 迁移到 0.7.1 的历史脚本，不用于当前版本构建。历史说明见 `docs/history-0.7.1.md`。
