# 异界弓藏 · Arcane Arsenal 0.5.0

新增七把白羊座几何光弓，共十五把中文武器。七把各有独立轮廓、配色和原生拉弓粒子，装在同一个 ESL 标记的 ESP 中。旧八把武器、配方、第一人称记录和光效任务编号保持不变。

采用有厚度的实体几何和自发光材质，不制作金属纹理。面、边线和弦分开设置亮度，白色保留灰面，黑色依靠细边线辨识。七把不是同一模型换色；基础握把、弦端和骨架使用此前已验证的参考。单把约 1.1–2.7 万三角面。

本轮统一基础伤害 20、重量 6、价值与附魔容量 1800，使用原版吸收生命附魔，方便集中比较外形和粒子。颜色不代表不同的伤害类型。每把均可用银锭 2 个、精炼孔雀石 3 个在锻造台制造，无技能条件；暂未添加磨刀石强化配方。

## 一次取出七把测试

通过 MO2 的现有 SKSE 启动，控制台输入：

```text
help "AAAriesTestChest" 4
```

找到 **白羊座·试武箱** 的 CONT 记录，用返回的完整编号执行：

```text
player.placeatme <CONT的完整编号> 1
```

不要输入尖括号文字。打开角色附近生成的箱子，即可拿到七把白羊弓各一把和铁箭 200 支。轻量插件的 FE 前缀取决于实际加载顺序，不能直接把表格里的本地编号当完整编号使用。

想同时对照旧八把，可查询 `help "AAAllBowsTestChest" 4`，生成 **异界弓藏·试武箱**，内含全部十五把弓和铁箭。旧箱子不会自动补货，请生成新箱子。单把也能用表中的搜索名查询 WEAP 后 `player.additem <完整编号> 1`。

## 粒子与测试重点

开始拉弓时显示粒子，保持拉弓时持续发射；放箭、取消、收弓、换武器时隐藏。新白羊弓不含六芒星。旧版赤光·叠弦的额外拉弓六芒星已关闭，其红色粒子保留；旧三把红弓本身的静态星形几何仍保留作对照。

七把均使用真正的 NiParticleSystem，每把六个发射点随弓翼的动画骨骼运动，避开握把和中心瞄准位置。不同版本分别改变粒子形状、颜色、方向、速度、寿命和密度。当前不包含环绕轨道、放箭爆发、箭矢拖尾或命中特效。

优先测试：

1. 七把分别检查第一人称握持、拉满时弦与箭尾的位置、弓翼是否连贯。
2. 拉弓、保持、放箭、取消、切换武器后，粒子是否按时显示和消失。
3. 拉弓时切换第一/第三人称，以及保存后重新读档，检查光效恢复。
4. 明亮室内和夜间各比较一次：粒子能否看清、白色是否过曝、黑色轮廓是否太暗。

脚本只控制玩家，暂不支持 NPC 拉弓触发。监听原版动画事件，并每 0.25 秒检查已拔出测试弓的拉弓状态；未装备时每秒检查。缺少取消事件且尚未进入满弓状态时，最多约 3 秒后回收。自定义动作包和 ENB 的表现仍需游戏实测。

隐藏粒子采用独立根节点的 0.0001 非零缩放，保证原生发射器逆变换有效，不改变弓骨骼。模拟本身仍循环运行：每个视角六个系统，各上限 24 个粒子，通常约 27–48 个可见粒子；第一和第三人称同时加载时，两个视角总池上限 288。新发光粒子比旧实验点更大、更亮，但没有通过堆积大量粒子制造光团。

如果所有新弓都没有粒子，先确认是从 SKSE 启动，再用 `sqv AARedDrawFXQuest` 检查任务是否运行。仅当任务未运行时，可用 `startquest AARedDrawFXQuest` 后重新装备测试弓。正常情况下 SEQ 文件会自动启动，不需要此命令。

## 安装与兼容

安装包为 `ArcaneArsenal-0.5.0.zip`。MO2 左侧模组名沿用 **Arcane Arsenal - Bow Collection**，右侧沿用 **ArcaneArsenal.esp**。当前更新已按此目录准备；安装工具会备份变更文件，并逐文件校验。已同步安装时不需要再导入压缩包。

meta.ini 版本为 **0.5.0**。MO2 若缓存旧版本号，刷新或重启后查看“版本”列。备份在工程 `build/mo2-before-0.5.0-*`。

插件扩展名为 ESP，但带 ESL 标记，使用轻量槽位；头版本 1.7、记录版本 44，新记录在 800–82F，适配 Skyrim SE **1.5.97**，无需扩展 ESL 支持补丁。主文件只有 Skyrim.esm。粒子触发依赖现有 **SKSE64 2.0.20 / NetImmerse**，不新增 DLL，不需要重新运行行为生成器。

完全退出游戏后再替换文件并通过 MO2 重启，让模型与脚本一起重新载入。安装脚本只维护本模组文件，不调整其他模组、存档、加载顺序或游戏 Data。

## 验证范围

- 七把均检查原版七根弓骨骼层级、归一化权重、非退化三角面、材质与 DDS 引用。
- 对每把比较静止、弓翼弯曲、握把带动三种受控姿态，导出前后最大位置差小于 0.003 个模型单位。
- 每把 96 个新增粒子块经过原生 nifly 读取、另存及引用归一化后的逐字段比较；另检查发射点位置、骨骼父节点、非零变换、容量和寿命。
- 插件包含十五条 WEAP、十五条 STAT、十五条 COBJ、两条 CONT 和一条 QUST，xEdit/SSEDump64 检查通过。旧武器记录逐字节不变，旧箱子仅扩展库存。
- AARedDrawFX.psc 已由现有 Creation Kit 编译，零错误、零警告。
- 打包与 MO2 安装各检查 60 个运行文件的一致性。

这些是离线检查，七把新弓尚待游戏内实测。`art/aries-bows-lineup.png` 是实际源模型的 Blender 渲染，未模拟原生粒子，也不是游戏截图；游戏中的发光、材质和 ENB 光晕会不同。本轮先交付可集中测试的实现，未宣称完整还原概念插画。

## 工程与既有内容

`source/aries_catalog.json` 保存七把名字、造型和粒子配置；`source/build_aries.py` 在 Blender 中生成模型、材质与预览，参数为 `-- ariesred` 等七个 key。生成后运行 `source/build_aries_particles.py` 追加原生粒子，输入为模型构建器生成的 `build/aries-base/*.nif`。再运行 `compile_draw_fx.py`、`build_plugin.py`、验证脚本、`package_mod.py`、`install_mod.py`。

`verify_rig.py` 与 `verify_aries_particles.py` 使用 Blender；`verify_draw_particles.py <key>` 使用普通 Python 与已配置的原生 nifly。`render_aries_lineup.py` 生成七把源模型合集和受控弯曲预览。模型重建后必须重新追加粒子。

旧八把：霜璃王冠、烬翼、星轨、月棘、冰龙脊骨、赤光·叠弦、赤光·旋序、赤光·流菱。它们的模型与贴图保持 0.4.2 内容。此前版本的制作记录保存在工程 `docs/history-0.4.2.md`，其中旧版操作说明不代表 0.5.0 的当前行为。
