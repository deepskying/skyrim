# 金牛座四弓 · 0.7.0

概念图位于 `../art/concepts/taurus-four-colors-01/`；实际模型总览为 `../art/taurus-bows-lineup.png`。概念图用于轮廓和配色指导，模型使用实体几何自发光，不复刻金属反射或绘画中的辉光笔触。

| 概念 | 实际模型 | 重点保留 |
| --- | --- | --- |
| 01-red-bullcrown.png | taurusred | 两侧粗大开口牛角、尖锐叠刃、红色主轨 |
| 02-mint-jadehorn.png | taurusgreen | 大菱框、青绿角刃、节点实心菱片 |
| 03-cyan-tidegate.png | taurusblue | 三条宽弧轨、四组横撑、弦端双角 |
| 04-violet-rifthorns.png | tauruspurple | 三层逐级缩小且有深度间隔的角叉、空心菱框 |

四种形状独立。几何沿同一原版弓骨架构建，握把位于 X=1.3、Y=0，弦端为 X=-13.674、Y=-54.70/+54.97。角片使用固定混合权重，长轨按截面分配权重；亮边复用对应截面权重，防止单独按位置取样造成弯曲后偏离实体。受控姿态用于检查导出和几何连续性，不代表游戏的最终拉弓动画。

使用 0.6.1 的邻色配色、贴图和发光参数。红为红/玫红，绿为翠绿/薄荷青，蓝为冰蓝/青蓝，紫为蓝紫/浅紫。泛光最终受游戏与 ENB 影响，本轮不修改 ENB。

粒子使用 Skyrim 原生 NiParticleSystem。红为三角碎屑，绿为柔光点，蓝为方形冰屑，紫为菱片；六个发射点分别绑定上下弓翼骨骼。它们是局部漂散，不是完整环绕轨道或发射后拖尾。triangle/square 为新增 sprite，mote/diamond 复用现有纹理；aa_aries 前缀是共享粒子资源名称，不影响金牛实际配色。

沿用已有 AARedDrawFX 任务与玩家别名。读档初始化八把星座武器，金牛使用与白羊相同的 AAAriesDust0–5 控制节点名，每把独立 NIF 内都有完整节点。旧额外拉弓六芒星仍隐藏。

旧十二把运行资源应与 `build/before-0.7.0/data` 逐字节一致，只有 ESP 的追加记录/总箱库存/头和 PEX 的武器名单扩展发生变化。新增 FormID 为 000830–00083C，退役三色编号不复用。MO2 版本号 0.7.0，插件继续 ESPFE。
