# 白羊系列当前决策（0.6.0）

当前只保留余烬·白羊（红）、流萤·白羊（青绿）、寒汐·白羊（蓝青）、梦隙·白羊（蓝紫）。用户已明确取消黑、白、黄；七色方案和七把齐全的要求已被此决定替代。后续星座暂以这四个颜色方向为准。

用户允许邻近颜色混合，追求初版红弓一样明显的荧光感和更粗壮的几何线条。0.6.0 使用更亮的配色底图、邻近色亮边、更高发光强度和更宽的弓轨，四把编号保持不变，退役编号不得复用。

以下为此前决策历史，涉及七色或固定纯色的部分不再适用于当前版本。

# 白羊座七色系列：已确定的设计约束

当前范围只实现白羊座七把。后续计划每个星座七色，十二星座共 84 把，尚未开始其他星座。

名字固定为：余烬·白羊（红）、鎏金·白羊（黄）、流萤·白羊（绿）、寒汐·白羊（蓝）、梦隙·白羊（紫）、夜蚀·白羊（黑）、月华·白羊（白）。

首三张概念位于 art/concepts/aries-red-selection-01：01-twin-horn、02-layered-crown、03-open-chevron。原图均为红色，实现按红、黄、绿分配。

后四张位于 art/concepts/aries-colors-selection-01：04-blue-twin-rails、05-purple-layered-horns、06-black-faceted-horns、07-white-open-horns。

保留各自几何轮廓，以有厚度的发光实体实现，不需要插画中的金属质感。弓面与亮边分层。新弓不带中心六芒星，拉弓时显示各自粒子。

0.5.0 七把采用独立几何和六处随弓翼骨骼移动的原生粒子。紫色目前是菱形碎光扩散，并未实现插画可能表现的环绕轨道；也没有放箭爆发、拖尾或命中特效。下一轮以用户游戏内统一测试为依据调整轮廓、粒子位置和亮度。

## 0.5.1 用户反馈调整

用户认为 0.5.0 线条太细、颜色像附魔且夹带流动红色、粒子不明显。已加粗线条和主体，移除七把的吸收生命预设附魔，改为同色相自发光；黑色使用黑色主体与中性灰光边。粒子增大、增密、提高发光并移近握把两侧弓翼。原编号不变，等待统一复测。

## 0.6.1 亮度反馈

用户认可 0.6.0 的效果，但觉得发光偏强。本次四把弓的主体、亮边和弦的发光参数统一降低 25%，其余外形、颜色、贴图和粒子保持不变，等待复测。
