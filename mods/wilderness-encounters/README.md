# 野外遭遇 · Wilderness Encounters 0.2.1

独立模组，当前测试版本 0.2.1。目标为当前整合的 Skyrim SE 1.5.97 + SKSE；使用 Papyrus 和 ESL 标记的 ESP，不需要 PrismaUI、Meridian UI、Fuz Ro D-oh 或独立 DLL。

## 玩法

- 普通袭击约 60%：强盗、狼、巨魔、剑齿虎，以及已安装的扩展怪物。强盗使用原版等级列表，继承整合对这些列表的修改。
- 小剧本约 25%：拦路勒索、真假问路、危险提醒、求援守阵。勒索可付款、威吓或拒绝；问路有 35% 的概率是骗局；危险提醒是和平事件；求援允许玩家与其中一方共同对抗追兵。
- 火拼约 15%：强盗与狼群交战，可以旁观、绕开或自行介入。第一版固定这组对手，后续可以增加其他组合。
- 每场随机 **3～20 名总参与者**，双方交战共用这个上限；和平案例也采用这个规模。普通袭击则全部为敌人。第一版均匀抽取人数，未按怪物强度缩减上限。
- 原版巨魔从玩家 10 级加入；扩展群落按各自等级门槛开放，从 10 级至 80 级不等。普通袭击的群落选择权重：强盗 25%、狼 20%、巨魔 10%、剑齿虎 10%、扩展群落 35%；没有满足等级要求的扩展池时回退到剑齿虎。高强度怪物不会自动削弱，20 只食人魔可能非常危险。
- 同时最多一场事件。默认启动 / 读档后至少 30 秒缓冲，首次安装 45 秒；默认采用「频繁」，事件后冷却 1.5～3.5 分钟，并要求玩家相对上次生成点移动至少约 1225 游戏单位。可以切回标准（3～7 分钟）或稀疏（6～14 分钟）；实际间隔还受当前事件清理和地点条件限制。

## 文字与生成位置

剧情使用**手动确认的中文文本选择框**，阅读时游戏暂停，文字不会自动消失。第一版没有原版面对面对话界面、角色配音或定时字幕；短暂 HUD 通知只用于提示附近有事件。

使用 Skyrim.esm 的 401 个原版场景中心 / 道路遭遇标记，筛选已加载的泰姆瑞尔野外、玩家身后 1800～4200 游戏单位、远离城市 / 城镇 / 玩家住宅的位置。标记附近 500 单位已有角色时跳过，尽量避免叠加原版事件。没有合适位置就稍后重试，不会强制在玩家脚下生成。

本版不覆盖索瑟姆、室内和其他模组新增世界；不支持真正的巡逻旅行 AI。非战斗事件参与者留在标记附近，靠近至 650 单位后触发文本。怪物生成使用标记附近 ±80 单位的小范围偏移，仍需实测地形适配。

仅清理本模组新建的角色。事件至少保留 5 分钟，全部成员离玩家至少 7000 单位或已离开当前世界 / 进入室内后才清理；当前世界中仍在战斗的成员必须离玩家至少 12000 单位。死亡成员保留期间可正常搜刮。暂停新事件会继续管理和清理已有事件。

## 扩展怪物

默认配置了 **119 组可选群落、377 个普通战斗模板，来自当前配置中的 37 个插件**。除原有 9 组外，加入 Mihail 树妖、牛头怪、眼魔、蜈蚣、机械生物、魔族、吸血兽、食尸生物等，以及 Monster Mod、Skyrim Immersive Creatures 和 Morrowind Creatures 的普通野外模板。每次从已安装且满足等级门槛的群落中等概率选择一组。完整来源、成员数量与开放等级见 [群落清单](docs/creature-pools.md)。

新增模板先按名字、角色 / 记录标记及自定义脚本筛选，再人工选定种类；没有直接导入所有 NPC。未接入家猫、宠物、坐骑、音频载体、驯养 / 被动角色、测试 / 删除记录、专用剧情变体、自带直接召唤 / 复制脚本的模板，以及水生 / 龙类。候选扫描共读取 84 个已启用相关插件、5321 条 NPC 记录。扫描不是运行时自动发现功能。

这些模组**不是 ESP 的前置依赖**：脚本通过插件名和本地 FormID 查找，未安装则自动跳过。自动排除 unique / essential / protected 角色；构建检查还排除 ghost / invulnerable 及带自定义 VMAD 脚本的选定模板。只使用核对过的普通战斗模板，未接入音频载体、宠物和任务专用角色。扩展怪物的基础装备、法术、死亡效果与掉落会保留，其阵营在新生成的实例上重置以控制本场战斗。

编辑 `source/pools.json` 可以增加群落，每组指定 `key`、`name`、`plugin`、十六进制本地 `forms`、`min_level`、固定的群落 `id`，并记录对应 `editor_ids` 供校验。不要重用或改变已有群落 `id`。目前仅接受 ActorBase，不接受 LVLN；不要填写完整加载顺序 FormID。修改后运行构建，JSON **不是游戏运行时直接读取的配置**，安装包中的副本仅供查看。

## 0.2.1 默认频繁

新安装默认频率倍率为 0.5；旧存档首次加载此版本时切换到频繁，并按旧倍率同比缩短剩余冷却。迁移只执行一次，之后保留玩家自行选择的频率。读档缓冲、同时一场、最低保留时间及生成位置条件继续生效。

## 0.2.0 升级

保留任务、阵营、小能力及原来 9 组群落的 FormID。加载存档时重建可选群落 FormList，以移除失效或旧配置条目；不清空当前事件角色，不要求重开存档或重置任务。读取扩展目录依然发生在初始化 / 读档时，未在每次计时器更新中扫描全部怪物。

## 安装与测试

在 MO2 中安装 `packaging/WildernessEncounters-0.2.1.zip`，勾选模组及 `WildernessEncounters.esp`。本次构建不会修改 MO2 的现有配置或游戏目录。

进游戏后自动获得可收藏的小能力 **「野外遭遇设置」**，使用它打开设置：开关、频率以及测试随机事件。建议用单独测试存档沿野外道路行走；测试没有位置时会给出说明。

若需指定事件类型，控制台可调用：

```text
cqf WEControllerQuest Begin 0
```

类型：0 普通袭击，1 勒索，2 问路，3 提醒，4 求援，5 火拼。仍受野外位置与已有事件限制。`cqf WEControllerQuest Settings` 可打开设置，`cqf WEControllerQuest Resume` 可修复更新计时器。

优先反馈：人数 / 压力、生成地形、是否容易遇到剧情、文本选择是否清楚、火拼双方是否正确、离场后是否清理。游戏内行为尚未实测；脚本编译与安装包结构检查不能替代实机验证。

## 构建

```powershell
python mods/wilderness-encounters/source/build.py
```

使用本机现有 Creation Kit 编译器和 Skyrim.esm，无需安装额外 Python 包。可用 `--game-root` 指定包含 `SkyrimSE` 与 `TOOLS/+creation kit` 的目录。先生成 ESP 与可选群落脚本，再编译四个 PEX、运行结构及模板检查、输出 ZIP。`python mods/wilderness-encounters/source/scan_creatures.py` 可只读扫描当前 MO2 生物插件，将完整候选报告写入忽略的 `build/creature-inventory.json`；它不会修改群落配置或 MO2。中文 Papyrus 源码使用 UTF-8 BOM，供现有编译器识别。

ESP / VMAD / MESG / 小能力二进制结构依据仓库中的 `reference/wbDefinitionsTES5.pas`；Papyrus API 依据本地游戏和 Creation Kit 源脚本。[Creation Kit 的脚本示例](https://ck.uesp.net/wiki/Complete_Example_Scripts/ru)介绍文本提示与脚本使用方式。
