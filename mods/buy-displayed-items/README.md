# 柜台直购 / Buy Displayed Items

Skyrim SE **1.5.97** 的独立 SKSE 插件。站在商店或旅店里，瞄准店家拥有的摆放物品，显示“购买（总价 金币）”；按原来的交互键直接付钱并拾取。无需打开交易菜单。

## 使用

1. 在 MO2 中安装 `packaging/BuyDisplayedItems-0.1.0-MO2.zip` 并勾选。
2. 使用匹配 1.5.97 的 SKSE64 启动游戏；需要 Address Library for SKSE Plugins 的 SE 版本。
3. 正常站立时购买，潜行时保留原版偷窃。金币不足只提示并取消，不会回退成偷窃。

不需要 ESP、PrismaUI 或额外快捷键。没有自动安装进现有 MO2 配置。

## 识别范围

- 同一个室内 cell，当前 Location 带 `LocTypeStore` 或 `LocTypeInn` 关键词。
- 物品原本拿取会被视为偷窃；原本可免费拿取的物品继续免费拿取。
- 物品的 NPC 所有者必须是店主，或其所有者派系中有店主。忽略具有犯罪追踪功能的派系，防止将整个领地的财物当作店家商品。
- 店主必须在同一个 cell 中加载、存活、非战斗、非敌对、不是玩家队友，并属于有商人货箱的商人派系。
- 支持酒、食物、药水、原料、杂物、箭矢、武器、护甲、卷轴和灵魂石。书籍、钥匙、金币、容器、家具、采集物不拦截。
- 排除带任务别名数据、禁用、删除或阻止激活的引用。特殊任务物品若没有这些标记，仍可能被识别为商品；需在实际整合包中检查。

这里只能根据游戏的归属记录判断，无法理解每件摆设的用途。客人物品若被模组错误设置成店家财产，也会被视为商品；缺少地点/归属/商人数据的模组商店则可能不识别。

## 价格与设置

修改 `Data/SKSE/Plugins/BuyDisplayedItems.ini` 后重启游戏：

```ini
[General]
Enabled=1
SneakToSteal=1
Chinese=1

[Pricing]
Multiplier=2.0
```

- 单价为 `ceil(物品基础价值 × Multiplier)`；整堆总价为单价乘数量。
- 倍率允许 1.0–10.0，默认 2.0。非法值回退至 2.0；零价值、非法数量和价格溢出的物品不出售。
- 第一版采用固定倍率，**不套用原版口才、议价 perk、种族或附魔折扣，也不增加口才经验**。价格按基础物品计算，不额外计入实例的强化/附魔价值。
- `SneakToSteal=0`：潜行时也使用购买。
- `Chinese=0`：使用英文提示。中文需要现有游戏字体支持。
- `Enabled=0`：不安装交互钩子。

## 交易处理

复核当前准星目标、所显示价格和数量后，先检查并扣除金币，再将物品所有权转给玩家，并调用原有拾取流程。保留原物品的额外数据，而非生成一个基础物品副本。

根据实际背包数量增量核对交付；被其他拾取插件阻止时恢复引用原所有权并退款，部分交付时只收实际取得数量的钱。成交金币存入识别到的商人货箱。交易失败不执行原版偷窃。

没有修改全局犯罪规则。已购买物品的所有权/背包和金币变化是正常存档变化，卸载 DLL 不会撤销已完成交易。

## 第一版限制与验证状态

- 已完成：1.5.97 目标 DLL 编译、交易单元测试；只读核对本机 `Skyrim.esm` 中母马横幅旅店和贝莱托杂货店的地点关键词、cell 归属、店主派系及商人货箱，符合上述识别条件。这不等于游戏内测试。
- 支持范围仅为 SE 1.5.97；其他运行时拒绝加载。
- 不判断开店时段、店主睡眠或商人自定义对话条件；店主满足上述在场条件即可成交。也不按商人的买卖类别列表过滤店内陈列物。
- 未修改 HUD 的犯罪颜色逻辑；某些 HUD 组合可能仍将“购买”提示显示为红色。
- 与修改玩家拾取或物品激活文字的其他 SKSE 插件需要实测兼容，尤其是异步/延迟拾取插件。本插件的交付验证依赖同步拾取。
- 构建与交易单元测试不能证明游戏内无悬赏、无赃物标记、HUD 正常及场景刷新后归属正确；这些属于下面的游戏内验收项目。

### 游戏内验收（尚未执行）

先用单独的测试存档，在有店主在场的旅店/商店检查：

1. 瞄准店家的酒，出现中文购买提示。记录金币、同类物品数量和悬赏；购买后桌上物品消失，钱和数量精确变化，无新增悬赏、赃物标记或 NPC 偷窃反应。
2. 金币不足时，物品仍在桌上且金币不变；连续按交互键不能获得免费物品。
3. 潜行时显示原版偷窃，站起恢复购买；自有/可免费拿的东西保持原行为。
4. 客人的私有物品、住宅/地牢里的物品、容器、任务物品不出现购买。
5. 店主离场、死亡、敌对或进入战斗后不提供购买；显示购买后立刻改变条件不能误偷窃。
6. 检查成堆箭矢与单瓶酒，费用等于实际数量；强化/附魔物品的数据和灵魂石状态保留。
7. 保存、重载后检查购买物品与金币；场景重置后陈列物的刷新和归属符合原设定。
8. 与当前拾取/HUD 模组一起运行，确认提示文字、字体、颜色和交易回滚正常。

日志：SKSE 日志目录下的 `BuyDisplayedItems.log`。

## 构建与测试

依赖仓库的 `reference/example-skse-plugin/lib/commonlibsse-ng`、Visual Studio 2022 C++ 与 xmake。

```powershell
cd mods/buy-displayed-items/native
xmake f -y -m release --skyrim_ae=n --skyrim_vr=n
xmake build -y BuyDisplayedItems
xmake build -y PurchaseTests
xmake run PurchaseTests
../packaging/package.ps1
```

交易测试覆盖整堆定价/逐件取整、整数溢出、非法配置、余额刚好/不足、扣款失败/部分扣款、拾取被阻止和部分交付退款。游戏 API、地点归属识别及其他插件的钩子行为需要游戏内验收。

接口依据：[CommonLibSSE-NG](https://github.com/CharmedBaryon/CommonLibSSE-NG)，以及项目内同库的 `TESBoundObject::GetActivateText` 和 `Actor::PickUpObject` 声明。拾取拦截可用于阻止偷窃的实作参见 [SureOfStealing](https://github.com/clayne/SureOfStealing/blob/main/src/Hooks.cpp)。本项目未复制该模组实现。
