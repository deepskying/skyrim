# 魔法箭工坊 — 1.1.0 扩展充能材料

## 统一工坊 2.3.7：辅助施法器归属

封存箭的施放由挂在隐藏标记物上的非角色施法器完成，而它不向引擎报告施法者：引擎创建的法术效果带着空的施法者句柄，脚本效果在 `OnEffectStart`/`OnEffectFinish` 收到的 `akCaster` 是 None。摄魂陷阱（法术 0004DBA4 → 脚本效果 0004DBA3，`magicSoulTrapFXScript`）正是靠 `OnEffectFinish` 里的 `Caster.TrapSoul(victim)` 收获灵魂石，`Caster` 为空就只剩一条 `Cannot call TrapSoul() on a None object`，敌人死在效果里也拿不到灵魂石；吸收与归属判定同样记不到实际射手名下。插件现在在安装时改写该施法器的 `GetCasterObjectReference`：只对「本模组 E00 标记物」、且只对接触与锁定目标两类路线，把引擎询问的 out-actor 指向我们传入的实际射手；自身、瞄准与地点法术的瞄准/抛射分支保持原样。已通过原生编译与 `spell-compatibility-test`；实机灵魂石与火/冰/雷、地点箭回归待验收。

## 1.1.0 扩展充能材料

充能匹配从「一个家族只认一个属性」改为「家族属性集合＋通用回退」,目标是让背包里绝大多数药水、毒药和原材料都能派上用场。家族属性集合:火／冰／雷＝对应抗性＋毁灭系威力(CACO 的「智力」用的就是毁灭系威力属性);蛇牙箭＝抗毒＋抗疾病;嗜血／圣辉箭＝生命＋生命恢复速度(圣辉另加恢复系);旋翼／碧波／岩锥＝耐力＋耐力恢复速度(旋翼另加速度,岩锥另加负重、护甲和变化系);影镰／星魂／奥术＝魔法值＋魔法恢复速度(分别另加幻术系、召唤／附魔系、魔法抗性)。原型接受 ValueModifier、PeakValueModifier 与 DualValueModifier;双属性功效按主属性和次属性各算一次取最大,使 CACO 改写的「减缓体力／减缓法力」重新可用。

不属于任何家族的数值型功效(技能强化、疲劳、自定义属性等)按 `MagicArrows.ini` 的 `[Crafting] GenericMaterialPercent` 折算后对任意家族生效,默认 50%,0 关闭,100 全额。治愈疾病、解毒、治麻痹、戒瘾、水下呼吸、水面行走、夜视、隐形、麻痹、恐惧／狂乱／平静／命令、侦测生命、念动、开锁、光／暗、延缓时间、束缚／召唤／复活／驱散亡灵、狼人进食、乙太化等纯功能与脚本功效始终不计;任务物品和食物继续排除,原材料仍要求已发现功效。多效果仍只取最高匹配充能,不累加。

玩家当前加载顺序的覆盖统计:炼金功效引用 3846 条,旧规则可充能 1437 条(37.4%),新规则覆盖 3225 条(83.9%)。原生 `material-charge-test` 覆盖家族匹配、通用回退、双属性、功能排除、发现限制、强度上限与最强取值,构建通过;两个面板都在充能材料栏显示「本配方接受」的功效范围与当前回退百分比。实机识别与扣除仍待验收。

## 1.0.0 排队制作

在附魔台附近点"开始制作"时一次性扣除金币、基材与充能材料，订单进入队列后即可离开附魔台：插件按当前法力逐支产出，每支发一条游戏原生通知（与分解提示同一通道），成品直接进背包。同一法术的多批订单合并为一条队列条目并保留原位置，不同法术按先来后到执行，同一时刻只推进队首一条。每个法术队列上限 10000 支，每个输入框上限 999；确认前只受金币、队列容量与附属存档可用性限制，不需要当场持有足够法力。队列进度与暂停原因随状态一起下发，统一工坊的左下角状态栏用菱形展示每个法术的剩余数量与进度，独立 MagicArrows.dll 在制作页列出同样的队列条目。详见 docs/craft-order.md。

暂停条件为战斗中（`MagicArrows.ini` 的 `[Crafting] PauseInCombat`，默认开）、工坊面板打开或游戏暂停、角色死亡与载入中；等待法力回复属于正常推进，不算暂停。法术失效、来源模组缺失或存档数据不兼容时，订单按未完成数量退还金币、基材与充能材料并提示，不需要取消入口。

材料充能改为完全按强度线性计算：`ceil(min(10000, |强度| × sqrt(clamp(持续/30, 1, 4))))`，10000 只是防溢出保护。单批可接受充能上限 100000，超出时按上限计算并提示，不再报错。订单随附属存档保存，读档后继续推进。

已完成队列上限、同法术合并、逐支进度、退款算术、余量标注、暂停优先级与附属存档往返的离线测试，加上两个面板的接线测试（独立面板 `craft-order-test.cjs`、统一工坊 `craft-order-hud.test.mjs` 与队列容量门禁），并通过统一 DLL、两个独立 DLL 编译和前端类型检查；左下角菱形的实机节奏与读档续做待验收。

装备页使用队列支持加入、拖拽/按钮排序、移除与库存徽章。普通箭、魔法箭和试作箭可混排，最多 64 种。

启用「队列优先」后，只要玩家装备弓，就自动使用有库存的队首；无需先点「从队首开始」。当前装备其他箭、刚切换为弓、读档或调整顺序后，也按队首执行。首次向空队列添加箭矢会开启优先；已有队列明确关闭的设置保留。需要自由手动选箭时关闭「队列优先」。

所有耗尽条目自动从队列删除，下一种成为新队首，全部耗尽则队列清空并沿用游戏行为；补充库存不会自动恢复已删除的条目。关闭优先或使用其他武器时也会清理零库存，面板打开/刷新同样整理。读档时等绑定和库存就绪再清理，避免把临时不可用的箭误删。

队列顺序和优先开关随角色正常保存，兼容 0.9.8 的 SKSE 附属存档。只处理玩家弓箭，不改变随从或弩矢。延用两帧/250 ms 的延迟装备与实际装备确认，拒绝/超时后不会每帧重试同一个队首；编辑队列、重新持弓或手动开始可重试。切换仍可能约半秒延迟，高速射击和第三方选箭模组的组合需游戏验证。详见 docs/ammo-queue.md。

已完成耗尽删除、队首优先、重排、装备失败抑制及保存结构回归测试；实机连续射击和读档行为待验收。

## 统一工坊 1.0.2：药水充能

制作魔法箭支持匹配功效的药水、毒药（包括自制成品）和原材料混用。列表优先药水，其次毒药和原材料，同类按充能量降序。成品无需发现功效，原材料沿用已发现效果限制；每瓶取最高匹配功效，按既有强度／时长公式计算，上限 100。任务物品、食物及不匹配效果排除。两条制作路径都在报价与确认时核查库存、任务保护和效能，确认前不消耗。详见 ../workshop/README.md。

## 0.9.7 同法术箭矢合并

同一法术只占一个运行时成品身份，不再以基材区分。不同基材、炼金材料与制作批次都加入同一成品数量；物理基础伤害统一为 8，绑定法术及其施放方式不变。一次混合多种基材只需要一个空身份，产量仍按实际材料充能计算。

打开工坊前自动整理玩家背包中的旧运行时封存箭：首次迁移优先保留该法术当前装备的旧 ID，否则保留最早的旧 ID；选择写入原生存档，之后不会随装备或制作顺序变化。其他旧 ID 保留原法术效果并永久占位，避免破坏随从、容器和飞行箭的引用；将其取回玩家背包、再开工坊即可合并。任务、附魔、自定义名称、收藏等特殊附加数据不自动剥除；迁移后另行装备的旧别名也不会被强制替换，先卸下再开工坊。

旧版固定爆炸适配与原法术封存的命中行为不同，旧固定适配不自动转换成运行时封存；固定适配的新制作也统一使用每种法术的首个成品和 8 点物理基础伤害。外观试作箭不参与法术合并。

验证：身份优先级、混合基材、部分产量、合并总数上限、7+7 合并、扣除/添加不足以及添加异常后的数量恢复已通过离线测试；实际游戏存档恢复和背包合并仍需验收。详见 docs/arrow-identity.md。

以下保留既有功能说明。

新增：静态材质箭身自发光强度 1.35、核心 2.0，保留纯色不透明和独立着色器，不增加装备粒子、动画或场景灯。实际辉光范围由游戏后期效果决定。

材料减耗读取玩家基础炼金术等级（0–100）：每支充能 = max(1, ceil(原充能 × (1 − 0.005 × 等级)))。100 级最多节省 50% 充能；按整点向上取整，实际材料仍按整份消耗。金币与法力保持不变。运行时封存与固定适配共用规则，报价和确认均在原生端重算，等级变化造成报价不同会要求重新报价。

制作弹窗顶部用图标＋数字显示减耗后的每支充能、法力、金币。基材输入自动限制到库存、单个输入框 999 支和单批 10000 支上限，小数向下取整、非正数归为 1、无库存取消选择；允许暂时清空输入，离开输入框时补为 1。服务器继续校验库存，不信任前端输入。

Esc 在有制作弹窗时仅关闭该弹窗，再按才关闭面板。游戏中由原生按下事件统一交给网页处理，DOM keydown/keyup 只阻止默认行为，不重复关闭；浏览器预览按一次 keydown 关闭一层。

参考本地 Marc 的 MarcArcaneBinding / MarcArcaneArrowCast / MarcArcaneArrowCastDirect 源码：此前瞬发箭仅调用单投射物 Launch，并按效果白名单拒绝脚本、多投射物、Rally 等，造成可制作范围过窄。本版从命中点通过原生 NonActorMagicCaster 施放完整法术；持续法术仍只启动一次并计时 3 秒，原法术自身条件、脚本和多投射物交由引擎处理。未复制 Marc 的脚本或要求玩家给弓附魔。

新增路线：瞄准型支持全部六种魔法投射物；敌对接触/锁定目标型要求命中存活角色；地点型使用命中位置；自身型仅开放敌对的瞬发范围效果。治疗及非敌对目标辅助、纯自身增益、斗篷、召唤、变身、念动和装备类效果仍不开放。脚本结构可接受不等于每个第三方脚本都已经游戏测试。详细对照见 docs/marc-compatibility.md。

用户已确认 0.9.4 装备可用；本版保留其静态发光装备模型、延迟装备和材料一键充能。0.9.5 扩展法术的命中效果、脚本和存档恢复仍待游戏验收。

本版针对「天体光芒」封存箭装备卡死调整：面板关闭后等待至少两个玩家更新帧、250 ms 且确认解除暂停，再重新校验库存并提交一次装备；日志区分提交与 GetCurrentAmmo 确认，读档取消未完成请求。背负/持握 NIF 移除粒子系统与动画标记，保留纯色发光形状；每个几何体独立使用着色器属性，飞行和命中粒子保留。当前只有卡死前日志，没有冻结调用栈；这些是排查修订，尚不能认定根因或宣称游戏卡死已解决。

成品名称统一为「箭名·法术」，不显示基材和封存后缀。内部身份从 0.9.7 起只按法术区分，物理基础伤害统一为 8；旧运行时成品在打开工坊时按上述规则整理。

默认法术页改名「可制作」，列表与数量统一依据最终 craftable 结果，不再把结构初筛当作可制作。治愈之触属于非敌对的目标治疗法术，归入「暂不支持」；敌对锁定目标法术现在有独立命中路线。未适配的其他效果放入「待适配」，保留明确原因；旧版本数据即使误标 candidate，只要 craftable 为 false，也不会进入可制作页。本版包含 0.9.2 的库存徽章、点击直接装备和已装备边框。

法力及金币使用双色条：蓝色代表制作后剩余，橙色代表即将消耗；两段合计当前持有量。数值不足时显示差额并禁用确认。右侧显示材料充能槽、符合条件的材料卡片与待消耗清单。点击一次按当前充能缺口和该材料库存尽量填满，可用减号撤回；确认前不扣库存。只消耗明确加入清单的份数，多余充能不返还。

选择法术后打开大号制作弹窗：勾选基材并填写各自数量，点击匹配炼金材料加入充能槽，自动更新实际产量和消耗数量、所需／当前法力及金币，最后确认制作。清单只读报价，确认时才扣除四项资源。不足以制作 1 支、法力／金币不足或清单尚未更新时禁用确认；过期响应不能授权当前选择。

## 运行时封存如何使用

1. 使用 Shift+W 或「魔法 → 能力 → 打开魔法箭工坊」进入制作页。
2. 选择标记「可制作」的已学法术。符合运行时条件的法术优先走通用封存；不限制法术学派或来源插件名单。
3. 勾选库存中的普通箭作为基材，包括第三方普通箭。当前不接收弩矢、爆炸箭、非可玩箭、没有稳定来源文件的临时箭或任务/附魔物品。
4. 点击具有已发现匹配功效的材料，一次按当前充能缺口和该材料库存尽量填满；右侧显示已加充能、目标充能和「可制作 X / Y 支」。实际数量为 min(基材目标数, floor(已加充能 / 每支充能))。如计划 10 支而材料只够 7 支，只扣 7 支基材，法力与金币也按 7 支计算。多种基材按勾选顺序使用，每种显示本次实际数量；多出的基材留在背包。每次最多 10000 支、32 种基材，每个输入框上限 999 支。
5. 成品形如「奥术箭·某法术」，界面标记「原法术封存」；基材仅在制作选择时显示。

同一法术重复制作使用存档内原身份并叠加；不同基材不再分开。材料效能改变消耗数量，不改变成品身份与法术。物理基础伤害统一为 8；施法时使用原法术引用。

## 保存身份

插件仅预留 256 个空 AMMO（0xC00–0xCFF）和 256 个空 FLST（0xD00–0xDFF），没有把任何第三方法术预填进去。第一次制作一种法术时，其 FLST 写入自身 AMMO 标记、源法术和主身份标记（既有 0xE00 STAT）；旧记录的基材引用保留但不再决定伤害或可用性。使用 BGSListForm::AddForm 与 kAddedForm 变化标记，让游戏保存这些引用。

读档后按引用类型重建名称、模型、伤害和绑定；不依赖玩家当前背包，因此同一身份可用于随从、箱子和世界物品。绑定映射不依赖单独的 SKSE 附属存档或外部配置。实际原生保存/加载行为仍须进游戏测试。

每个存档最多 256 种组合，已分配身份不会因箭用完而回收。来源缺失、重复或不兼容的记录保持占用，显示为不可用，不删除物品或把旧箭改绑其他法术。删除来源模组后不能保证重新安装即可找回引用；恢复原存档是保留完整引用的途径。新游戏和读档由引擎恢复各自 FLST，不将上一个角色的绑定作为新角色数据。

## 当前运行时支持范围

源法术须具有稳定插件来源，是瞬发或持续释放的普通法术。0.9.5 按 aimed、敌对目标、地点、敌对瞬发范围四种路线接入完整施放，不再使用脚本/数值 archetype 白名单或单一投射物限制；边界详见 docs/marc-compatibility.md。

瞬发箭命中后，捕获真实射手、目标句柄、位置和入射方向，在游戏线程建立落点辅助参考并使用原 SpellItem 施放完整法术。瞄准型从落点前方朝落点释放，敌对目标型使用被箭命中的角色，范围型以落点为中心。通过 ArrowProjectile::AddImpact 的 1.5.97 虚表回调接入，保留之前的回调链；按箭的句柄去重，限制排队数量，并在读档时使旧任务失效。

此过程不调用角色的普通手部施法或重复支付制作魔法值。射手失效/死亡、落点所在单元卸载或引用不兼容时取消释放。它不是完整重演玩家的原施法流程：条件附加投射物、天赋、连锁及附着脚本是否完整工作，仍需具体法术实测；不会据此宣称所有魔法模组自动兼容。

斗篷、纯自身增益、召唤/复活、变身、念动和装备类效果尚未开放；脚本附加、敌对接触/锁定目标和地点施法已接入。网格会列出限制；奥术兜底只决定载体外观，不绕过上述条件。

## 持续箭的命中行为

命中后在入射方向上、落点前方 12–64 游戏单位建立隐形施法点，并在落点建立固定瞄准点。使用 NonActorMagicCaster 对原法术调用一次 CastSpellImmediate，传入实际射手作为归属；由引擎的持续施法管理器更新投射物。插件不逐帧重放瞬发法术，也不占用射手的手部施法器。瞄准型喷射朝向固定落点；目标型法术对被箭命中的角色生效，最多持续 3 秒。

插件以游戏更新的时间计时，面板暂停不推进计时，3 秒后调用 InterruptCast 并禁用、删除两个临时标记。射手死亡/失效、落点单元卸载、原施法停止时提前清理。最多同时 16 处，第 17 处开始前结束最早的一处。原法术自身时限可能让释放更早结束；尾迹和效果淡出仍由原法术资源决定。

新增 0xE00 编辑器标记型 STAT（沿用原版 XMarkerHeading 的隐藏标志和模型）及 0xE01 空 FLST，登记当前临时引用。存档捕获到的在途释放在读档后结束并删除，不恢复其剩余时间；背包、箱子和随从中的封存箭绑定仍按原规则恢复。此 FLST 与 256 个箭矢身份列表互相独立。

本地 1.5.97 引擎静态分析确认非角色施法器会注册瞄准型持续法术并自动更新，详见 `docs/concentration-design.md`。持续伤害、停止音效/粒子、自动存档清理、友伤、随从和第三方天赋/脚本仍须游戏验收。

## 元素与运行时费用

依据每个效果的抗性字段、关键词以及吸血/灵魂陷阱特征评分，选择火、冰、电、毒、血、光、风、水、土、暗、灵或奥术载体。不按整部模组归类；没有匹配或最高分并列时使用奥术箭。关键词主要按常用英文编辑器标识识别，少见自定义标签可能落入兜底。

设当前施法参考费用为 C；持续箭先将 C 乘以固定时长 3，再执行同一费用公式。每支消耗 1 支基材，以及：金币 ceil(C/20)，范围 1–100；魔法值 ceil(C/2)，范围 1–500；材料充能 ceil(C/4)，范围 1–250。报价后若费用、库存或元素发生变化，确认会拒绝并要求重新报价。

材料只取已发现的适用 ValueModifier/PeakValueModifier 功效，同一件取最高充能。火/冰/电/毒匹配对应抗性功效；血/光匹配生命值功效；风/水/土匹配耐力功效；暗/灵/奥术匹配魔法值功效。这些是本版的材料平衡规则，不代表所有元素本质相同。

充能计算仍为 `ceil(min(100, abs(magnitude) * sqrt(clamp(duration / 30, 1, 4))))`，按待消耗清单的明确份数消耗整件，余量不退。降低基材目标不会自动移除已加材料，请根据余量提示自行撤回。确认使用一次性令牌，复查后扣资源并添加成品；异常会尝试恢复。失败时已写入的身份可能继续保留，避免以后错绑物品。

这一节仅描述旧版固定适配成品。这是固定元素效果适配，不是复制原法术：冰锥与闪电被适配为命中点小范围元素爆发，不会再发射一枚原法术投射物；不继承完整原法术附加效果、脚本、减速、冲击或法术天赋。载荷使用原版火/冰/电武器伤害 MGEF，冰电的附带资源伤害依原版效果与当前覆盖记录而定；闪电伤害效果持续参数为 1 秒，不代表已实现持续施法。最终表现受抗性及其他模组影响。

原生链路：AMMO → PROJ → EXPL → ENCH → MGEF。保留爆炸视线检查，没有额外物理爆炸伤害/冲击力。不要求特殊弓，战斗时不再次支付制作魔法值；归属交给实际原生投射物处理，未把施法者写死为玩家。随从、友伤与实际伤害仍待游戏实测。

炼金充能仅使用已发现的对应 ResistFire/ResistFrost/ResistShock、ValueModifier/PeakValueModifier 功效。每件取最高合格效果，计算为 `ceil(min(100, abs(magnitude) * sqrt(clamp(duration / 30, 1, 4))))`。材料按玩家添加的份数混合充能，旧版固定适配也采用相同的部分产量规则；只消耗整件，多余充能不返还，不改变成品强度。

报价使用一次性令牌。确认时重新检查已学法术、基材、材料功效/效能、金币与当前魔法值，再执行扣除和添加成品；检测到异常会尝试恢复。外部脚本同时更改库存的情况仍需游戏验证。

## 面板与十二种外观

装备、制作、设置三个视图保留。Esc、右上角关闭按钮或再次按快捷键关闭；能力入口读档自动添加。制作弹窗主要中文字号 20–28 px，库存说明 18 px；列表较长时独立滚动。装备卡片右上角用徽章显示库存；点击可用且未装备的卡片直接发送装备请求，先关闭面板，等游戏恢复更新后再由原生插件提交装备。当前已装备卡片按游戏返回的 IsWorn 状态显示青绿色边框与「已装备」标签，点击本身不会伪造高亮。重复点击、失效箭与零库存不会发送装备请求。安装保留已有 INI。

十二种外观及 36 个 NIF 保留：火焰、霜晶、雷棱、蛇牙、嗜血、圣辉、旋翼、碧波、岩锥、影镰、星魂、奥术。测试用「补充试作箭」入口及免费补给接口已移除，已有物品与外观资产保留。

## 随从使用与消耗

将封存箭或固定适配箭交给随从并让其装备弓，命中执行使用实际射手，不要求随从掌握原法术。默认在射击时按数量消耗，射空也计入；原游戏或其他模组已扣除的数量计入核算，只补扣不足部分。耗尽时清理空箭装备，后续选箭仍由游戏 AI 处理。

在“设置 → 随从魔法箭消耗”可以关闭补扣，沿用游戏及其他模组规则。设置保存在 INI 的 [Followers] ConsumeMagicArrows，缺省开启；不改快捷键或能力设置。这里只将 IsPlayerTeammate 标记的角色视为队友，特殊随从框架若不设置这个标记不会进入补扣。普通箭、外观试作箭和其他模组的魔法箭保持原规则。

本版没有新增友伤保护、自动选箭策略或随从物品分发。与异步退款/自定义发射模组组合的行为及实际最后一支箭耗尽流程未游戏验证。原生接口、缓存同步与测试边界见 `docs/follower-ammo.md`。

## 普通箭制作

制作 → 普通箭矢 → 选择配方 → 批数 → 计算费用 → 确认。读取已加载游戏/模组中 CraftingSmithingForge 的普通箭配方，采用当前生效材料和每批产量；每次最多 100 批、1000 支。相同材料条目合并，任务或附魔物品不计入可用材料。

便携工坊不要求站在锻造台旁，不额外加收金币/魔法值，不授予锻造经验，也不模拟原工作台事件。条件使用游戏原生整条条件链，保留 AND/OR 关系；只接受自身执行的天赋、物品数量、属性值、全局变量、种族/身份、等级、任务阶段/完成条件。报价和确认均检查，特殊工作台/目标/别名/包数据/其他条件须回原工作台制作。特殊材料、爆炸箭、弩矢不在当前普通箭交易范围。
