# 0.9.9 玩家箭矢队列：耗尽删除、持弓队首优先

装备页支持加入、拖拽/按钮排序、移除、库存徽章和装备高亮。最多 64 种，支持普通弓箭、魔法箭和试作箭，不处理弩矢或随从队列。

## 行为

启用「队列优先」后，玩家装备弓时自动优先使用有库存的队首。刚换为弓、无弹药、原版已自动选中另一种箭、读档或改变队首时均适用，不再需要先点「从队首开始」。需要自由手动选箭时关闭优先，否则下一次检查仍会优先队首。

首次向空队列加入箭矢会自动开启优先；向已有队列继续添加则保留开关状态。「从队首开始」仍可以立即发起装备及重试。原生请求拒绝重复、非整数、超长队列，以及不在背包中的新条目。

所有零库存或不可用条目自动移除，不再只跳过。当前用尽后下一项成为新队首，全部用尽则队列清空并沿用游戏行为；补充库存不会自动恢复已删除条目。移除队列条目不消耗物品。

## 清理和保存

有效游戏更新时先清理，再判断开关和弓武器，所以关闭优先或切为其他武器也会清理；面板打开/刷新和队列编辑也会清理。读档恢复绑定之前不清理，不将临时中立化的法术箭误当成空库存。

沿用 0.9.8 的 SKSE 附属存档结构，正常保存时写入顺序与开关，读取通过 ResolveFormID 恢复。无记录的旧档默认空队列、关闭优先。新游戏或切换存档清除上一角色状态。法术箭仍按 0.9.7 主身份归并旧别名并去重，没有新增或重排 ESP 记录。

## 装备调度

使用既有 PlayerCharacter 更新回调，每 250 ms 最多安排一次 SKSE 主线程检查。暂停、面板焦点、死亡、没有 3D、加载界面时不自动装备；没有持弓时重置尝试状态。

直接选择队首；已经装备队首时不重复请求。不再把手动选到的其他箭作为新游标，也不会因原版抢先选中其他弹药而取消队首优先。

保持至少两次更新、250 ms 且解除暂停后才提交一次 EquipObject，以 GetCurrentAmmo 确认。自动请求复核存档代次、队列修订、武器、目标库存和当前队首。拒绝或超时后不反复尝试同一队首；重新持弓、编辑队列或「从队首开始」可重试。

轮询及延迟提交仍可能约半秒。高速射击和第三方自动换箭组合必须实测，不能保证它们不会抢先发射一支原生选择的箭。

## 验证

- ammo-queue-test：耗尽实际删除、多个/非队首耗尽、补货不复活条目、持弓时无弹药或任意其他弹药仍优先队首、重排、已装备不重复提交、失败抑制、重置重试及保存结构边界。
- ammo-queue-test.cjs：拖拽/按钮排序、去重、容量边界、首次加入自动开启、已有队列关闭状态保留。
- 原生 DLL 编译与发布资源校验。
- 待实机：队首留一支射完后切下一项，打开面板确认旧项消失；原先装备队尾或队列外箭，改持弓后切至队首；重排、读档、暂停及关闭优先行为。

离线测试和编译不能替代实机验收。
