# 已确认方向与待验证实现

## 用户确认的玩法

- 12 种外观载体：火、冰、电、毒、血、光、风、水、土、暗、灵、奥术。
- 无明确匹配时使用奥术箭。按具体法术/效果匹配，不能按整个模组统一分类。
- 本轮确认名称：血为嗜血箭，光为圣辉箭，水为碧波箭，灵为星魂箭。
- 模型为纯发光能量箭矢，不采用木杆、金属、实体羽毛的写实概念图。
- 成品显示“箭名·法术名〔基材〕”。不同法术/基材不能仅改名伪装成独立物品。
- 制作入口：Shift+W 和打开相同面板的能力。0.2.0 已实现入口，待游戏内验收。
- 从玩家已掌握的、适合封存的法术中选择。
- 必须选择实体箭作基材，每支实体箭转化一支成品。保留基材的基础物理伤害。
- 消耗金币、魔法值和炼金材料；炼金材料按功效匹配、效能折算充能量，可混合投入。
- 材料来源不改变成品强度；法术和基材相同的成品合并堆叠。
- 战斗时只消耗箭，不重复支付制作时已经支付的魔法值。
- 随从用箭应以实际射手作为施法者，不可照搬 Marc 脚本内固定的 Game.GetPlayer()。

## 仍需技术验证

- 任意第三方法术的持久 AMMO 身份：运行时动态记录、预生成记录或其他方案尚未确定。
- 多法术/多基材的保存、读档、删除模组后的解析行为。
- 射手、命中目标与法术调用上下文；复杂脚本法术与持续引导法术不能宣称自动兼容。
- 随从箭矢消耗受原版/NPC设置与整合包影响，需要独立处理并实测。
- 效能不同单位需归一化；金币、材料权重、法力倍率尚未定数值。
- 只使用已发现的炼金功效、锁定珍贵材料、自动补足等为已讨论的界面设计草案。

## 面板结构（用户新增确认）

面板包含三个顶层视图，Shift+W 与能力魔法进入同一个面板。

### 1. 装备视图

- 以网格展示玩家当前库存的箭矢与各自数量。
- 同时展示普通箭矢和魔法箭矢；不同法术、不同基材的成品分别展示。
- 建议卡片显示名称、数量和当前装备标记，选择后查看详情并装备。
- 建议提供全部/普通/魔法筛选与名称搜索，便于管理大量绑定法术的箭矢。

### 2. 制作视图

- 同时支持制作魔法箭矢和普通箭矢；视图内分为两种制作模式。
- 魔法箭模式沿用已确认的法术、实体箭基材、炼金材料、金币和魔法值制作流程。
- 普通箭模式先选择箭种，再显示其配方、可制作数量和消耗。
- 普通箭的配方来源（读取现有配方或由本模组提供）及是否限制技能/天赋/工作台条件，尚未确定。
- 普通箭是否另收金币尚未确定，不能自动套用魔法箭的魔法值/炼金充能规则。

### 3. 设置视图

- 用于配置本模组设置，包括面板快捷键（默认 Shift+W）。
- 建议后续加入界面显示、材料自动选择与锁定、发光/粒子设置及恢复默认值。
- 上述建议设置项并非全部已实现或已确定技术方案；只展示实际生效的选项。

0.2.0 已实现三个视图、真实库存装备、快捷键设置和能力入口。制作页为真实数据流程预览，尚无资源扣除和成品生成。

## 当前原型界限

0.2.0 仍只有三个固定 AMMO 物品，使用固定的物理伤害 8。命中粒子不等于法术绑定。
用户先查看三个箭型后，再决定外观调整和下一阶段功能实现。

## 0.2.1 已实现的制作选择

法术网格与右侧详情取代法术下拉框；可多选基材，每种基材独立填写数量，未来输出不同物品组。当前页面预览不会提交制作交易。
法术准入与元素外观分类分开：先根据完整效果结构筛选，再决定火／冰／电等载体。奥术兜底只负责外观，不代表无法识别的法术一定可以封存。
筛选为结构候选、待适配、暂不支持三态，显示原因；复杂法术将来以插件名和本地 FormID 维护适配规则。当前尚未实现自定义规则文件或第三方脚本自动识别。

## 0.2.2 修正

持续引导不再一概排除，新增持续型候选标记；仍无制作交易和命中执行层。未来采用有期限的命中点施法对象，保留实际射手归属；依据与边界见 concentration-design.md。此条取代前文对持续引导的统一排除。
十二种箭的形状已形成统一审阅图；新增九种暂为模型草案，用户审阅后再做游戏资源接入。

## 0.3.0 首条制作链路

火球术固定适配已实现：八种基材对应静态 AMMO，原生爆炸与火焰附魔链、5 金币／12 魔法值／10 材料充能每支、报价确认交易。此条取代前文「所有制作尚未接入」的状态。任意法术动态物品和持续施放仍待实现。详细机制与游戏验收步骤以 README.md 为准。

## 0.4.0 十二箭型与普通箭制作

此阶段接入十二种载体的游戏资源，普通箭制作使用现有锻造台配方、原生条件检查和报价交易。便携制作不额外收费/扣法力，不增加锻造经验；未知上下文条件不绕过。新增九个试作 AMMO 使用 0xA00–0xA80，原 ID 不重排。此条取代前文「新增九种只有草案」与「普通箭尚未实现」的状态。任意魔法与持续释放仍待实现，详见 README。

## 0.5.0 三系固定适配

已实现火球术、冰锥术、闪电术及按三系已发现炼金功效匹配的制作流程，共 24 个固定成品 AMMO。冰电是半径 96 的命中点元素爆发，非原法术完整复制；各收 4 金币、8 魔法值、8 充能与 1 支基材。火球配方和旧记录保留。任意魔法及持续施放仍未实现，当前状态以 README 为准。

## 0.6.0 运行时封存首版

新增 256 组空 AMMO/FLST，在游戏中制作时建立原法术＋任意合格普通箭基材的映射；引用写入原生存档，不预生成第三方法术配置。符合结构的瞬发飞弹/光束从命中点前方释放主投射物，实际射手归属。缺失引用不回收身份。此条取代前文「运行时绑定尚未实现」；实际保存重载/命中行为还未游戏验证，复杂附加效果和持续施法未完成。详见 README。

## 0.7.0 持续封存执行层

结构兼容的 Aimed＋Concentration 法术现在可制作；命中后创建独立固定施法点，使用原生 NonActorMagicCaster 单次开始，由引擎持续更新，3 秒后中断清理。实际射手归属，三秒参考量参与制作费用，16 处上限，原生 FLST 记录临时点用于读档清理。此条取代前文持续执行层未实现的状态；游戏内验证仍未进行。外观、固定配方和 256 组身份不重排。详见 README 与 concentration-design.md。

## 0.8.0 随从消耗

新增 Actor::UseAmmo 定向核算，只给队友使用的本模组法术箭补扣原规则未扣的射击消耗，设置页可关闭。按本次发射数与库存差额处理，保留原回调和实际射手命中路径；耗尽清理空装备。原 ESP 身份与资源记录不变。此条取代随从消耗规则未实现的状态，真实战斗和随从框架兼容仍待游戏验收，详见 follower-ammo.md。
