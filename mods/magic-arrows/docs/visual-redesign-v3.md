# 魔法箭能量造型 V3 / 资源包 3.0.0

V2 的低强度受光外壳在用户的游戏环境下缺少发光感，多个尖锥包刃造型也过于接近嗜血箭。本版恢复整支箭的能量形态：全部可见网格使用与已获认可的嗜血箭同类的 BSEffectShaderProperty，开启 OWN_EMIT、深度测试与深度写入，实体强度至少 1.35，局部核心 1.85。箭杆、尾翼与箭头全部自发光，不依赖环境照明，也不只依靠一条细光芯。

十一种新箭均另做不同轮廓与尾部：火为偏侧弯曲火舌，冰为细长冰刺与错落短晶簇，雷为分叉实体雷电，毒为无中央尖锥的开放双蛇牙，圣辉为椭圆光环加尖针，风为空心螺旋钻，水为后端饱满的圆润水滴，土为宽口岩凿，暗为单侧弯钩，星魂为分离悬浮晶簇，奥术为空心三角框架与小符文核心。嗜血箭三份 NIF 原样保留。

实际模型预览在 `art/visual-v3/overview.png` 与 `heads.png`。预览读取最终 NIF 的顶点、法线、UV 和实际材质颜色/自发光强度，辉光仍是 Blender 的近似。整体采用实体能量光，不提供概念图里的金属雕花或透明折射。

资源版本为 3.0.0；基础模组 ESP、DLL 与游戏逻辑不变。使用同一模型路径的旧存档箭矢也会显示新外观。挂点、原版碰撞、背部五支箭排列与飞行/命中特效沿用现有结构。

## 安装与恢复

在 MO2 将 `MagicArrows-Visuals-3.0.0-MO2.zip` 安装为独立模组，排在包含魔法箭资源的装备工坊之后。如果启用了 V2 外观覆盖模组，应关闭 V2 或让 V3 的优先级更高。本版只有 22 个 NIF 与 solid.dds；无需新增 ESP。关闭独立覆盖包即可恢复基础模组。

用户授权直接更新现有装备工坊时，仅覆盖对应模型与 solid.dds，先在 `mod-backups` 保存旧资源，保留嗜血箭、所有命中特效、ESP、DLL、INI 与 MO2 配置。安装记录保存到 `build/visual-installation.json`。

## 验证范围

构建入口仍为 `source/build_models.py`；资源检查使用 `source/verify_release.py --models-only`；预览使用随附 Blender 执行 `source/render_catalog.py`；打包使用 `source/package_visuals.py`。

离线检查涵盖 36 个 NIF 的原生重读、节点与材质/贴图引用、原版挂点和碰撞字节一致性、顶点范围、有限法线、非退化三角形与粒子寿命。新增发光回归检查：每个实体网格都必须使用 BSEffectShaderProperty、OWN_EMIT 与至少 1.35 的自发光强度。ZIP 文件重读并逐文件校验 SHA-256。

旧的完整记录校验仍因既有 spell_adapters.h 与旧生成器接口不一致而失败，本轮只验证资源，不重建 ESP 或原生头文件。V3 未在游戏中验证；需观察箭杆与箭头亮度、背部箭列、各家族轮廓、第一人称遮挡以及 ENB/Community Shaders 下的辉光。自发光材质不会自动添加照亮周围环境的动态光源。
